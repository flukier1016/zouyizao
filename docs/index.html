招牌玩法

平平淡淡是一世，逆天改命也是一世

01 · 爽文人生

从村里普通人家，到博士、身家过亿

嫌平淡，就开一局爽文：金手指开局，一路往上读、做到行里最顶，把当年瞧不起你的人一个个打脸。

  • 金手指：重生、系统、学神、商业鬼才、天选之子，花轮回点挑一个
  • 打脸回场：嫌你穷的前任、冷眼的亲戚、开除你的老板，等你翻了身会在同学会、喜宴上重逢
  • 高光印和逆袭值：第一次身家过百万、千万、亿，当上老板，各盖一方朱印
  • 五满：读到博士、做到行里最顶、身家过亿、活过八十、成家有孩子
02 · 命题人生

一题一世，拿满三颗星

命题簿里十二道题，每题定好出生：1977 年的考场、九二年南下、留守的孩子……三个目标各算一颗星。另有八个爽文剧本，开局就送金手指。

  • 今日命运：同一天的人拿到同一组出身，行情也一样
  • 同卡挑战：把出生卡发给朋友，同一张卡各活一世，对照谁活得更好
  • 速写一世：小事替你选，五到十分钟活完一世
03 · 时代的浪潮

1950 到 2049 年，钱按当年的价

八十年代挣的、花的，大约是现在的五分之一。经济在繁荣、衰退、危机之间切换，下岗潮、房价起落、AI 浪潮按年代找上门。

  • 世界面板：政策利率、2 年和 10 年期国债、通胀、信用利差、汇率和中美利差
  • 理财：存款、国债和信用债基金、指数、18 只个股、黄金、数字币、房子
  • 二十八种世界大事：金融危机、牛市、大流行、延寿药、火星殖民
04 · 家族传承

走完一世，让孩子接着活

遗产、房子、公司和家风都带过去；结局页写“某氏第三代”。嫌一年一年点太慢，就交给托管，选“一直传下去”，一代一代自动往下过。

  • 家声：上大学、做到高位、儿孙满堂都给家里添分，一到十级
  • 三代目标：书香门第、富过三代、五代传承，八个
  • 遗嘱和家业：钱按份数分，房子公司单独指给谁；二代可能做大，也可能败光

常见问题

玩家常问

要花钱吗？

不用。打开网页就能玩，不用注册，也不用下载；赞助完全自愿，不赞助也能玩到全部内容。

存档在哪？

默认存在你自己设备的浏览器里，关掉网页再打开还在。登录云存档以后自动同步，换手机、换电脑都能接着玩；设置里随时能删除账号和云端存档。

手机能玩吗？

能。电脑、平板、手机竖屏都排过；打开过一次以后，没网也能玩。

大陆能打开吗？

主站 zouyizao.com 打不开或者很慢时，用大陆镜像 cn.zouyizao.com，玩法和存档方式一样。

游戏里的人和钱是真的吗？

不是。人物、公司、学校都是虚构的；股市、基金、黄金都是模拟，只用游戏里的钱，不能充值、不能提现。

有问题或想法怎么反馈？

在 GitHub Issues 里提，或写信到 hi@zouyizao.com；游戏里“设置”最下面也有“意见反馈”。
